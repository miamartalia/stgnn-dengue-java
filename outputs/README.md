# Outputs directory

This directory is populated automatically when the notebooks are run. It will
contain model checkpoints (`.pt`), cached per-seed predictions (`.npz`), result
tables (`.csv`), and figures (`.png`).

These artifacts are **not committed** (see `.gitignore`) because they are fully
regenerated by running the notebooks with the five fixed seeds (42, 123, 456,
789, 2024). Running the notebooks end-to-end with the restricted input data and the specified environment regenerates the tables and figures reported in the paper.
